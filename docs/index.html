Modelo de churn: evaluación honesta

Se entrena un Random Forest con variables de uso, soporte, MRR y plan. Las métricas holdout muestran que esta versión no tiene señal predictiva suficiente para orientar acciones reales de retención.

Estas métricas pertenecen a una partición sintética de demostración. El resultado debe analizarse según la población, el período y los objetivos de negocio; no representa rendimiento en producción ni recomienda contactar clientes.

Cómo está construido

El flujo de ingeniería completo se ejecuta localmente. Esta página pública usa solo un JSON agregado y recursos estáticos alojados en el mismo repositorio.
